# 干扰项与输入判定手册

这个技能生成四个模式：

| 序号 | 模式 | 作答方式 |
|---|---|---|
| 模式一 | 看中文写日语 | 输入 |
| 模式二 | 看日语选中文 | 四选一 |
| 模式三 | 看汉字写假名 | 输入 |
| 模式四 | 看假名选汉字 | 四选一 |

只有两个选项模式需要设计干扰项；两个输入模式按字符串严格判定。

---

## 模式一：看中文写日语（输入）

题面显示中文释义，用户输入对应的日语单词。

- **答案接受汉字写法或假名读音**：例如「四川」或「しせん」都算对；
  「冷たい」或「つめたい」都算对。
- 比较前统一做 NFKC（全角/半角归一）并去掉首尾空格。
- **不做平假名/片假名互换**：标准写法是 ビル 就要求 ビル，写 びる 算错。
- 带前导省略号的词（如「…冊」）去掉省略号也接受。
- 输入为空不判分，焦点留在输入框。
- 如果多个词共享同一中文释义（如「敬启」对应 拝啓 / 敬具），
  任一对应写法都算对。
- 不需要任何干扰项数据。

## 模式二：看日语选中文（选项）

题面显示汉字和假名注音，四个中文释义中选一个。干扰项从下面几类里挑：

### 1. 语义家族
同一场景或同一概念群里的词，最容易混。

| 正确项 | 干扰项示例 |
|---|---|
| 受害、损失 | 灾害、灾难 / 伤亡、死伤 / 赔偿、补偿 |
| 死者 | 伤者 / 失踪者 / 幸存者 |
| 救护车 | 消防车 / 急救室 / 救援车 |
| 发现 | 发明 / 发生 / 发起 |

### 2. 近义动词
优先选字面相近但含义有差别的词。

- 发生 → 发现 / 发起 / 产生
- 带来 → 带走 / 拿来 / 招致
- 损失 → 损害 / 损耗 / 遗失
- 救出 → 救助 / 抢救 / 解救

### 3. 同一语义场
敬语、亲属称谓、考试、媒体、方位、量词等成组设计。

- 尊敬语 → 谦让语 / 郑重语 / 敬体
- 妻子 → 丈夫 / 女儿 / 母亲
- 口试 → 笔试 / 面试 / 口述考试
- 以上 → 以下 / 以内 / 以外

### 4. 专有名词按类别配
- 地名配邻近地名：四川 → 重庆 / 陕西 / 甘肃
- 人名配形近人名：刘红丽 → 刘红梅 / 张红丽 / 王红丽
- 报纸名配同类报纸：人民日报 → 中国日报 / 光明日报 / 新华日报
- 作品名配同类作品：我是猫 → 我是狗 / 猫的日记 / 人间失格

### 5. 易混点
- 词性陷阱：把名词释义配成动词释义。
- 方向/反义：以上/以下、目上/目下、左/右。
- 量词搭配：…辆、…台 → …张、…片 / …本、…册。
- 双重含义：只放该词在本课中的义项，避免把它的另一个义项当干扰项。

## 模式三：看汉字写假名（输入）

题面显示汉字，用户输入假名读音。

- 直接和词表里的假名读音比较，**严格按标准写法**：
  平假名、片假名不互换；例如 ビル 不可以用 びる 代替。
- 比较前统一做 NFKC 并去掉首尾空格。
- 输入为空不判分。
- 不需要任何干扰项数据。旧版“假名变形选项”已不再使用。

## 模式四：看假名选汉字（选项）

题面显示假名读音，四个汉字写法中选一个。核心是两条：

### 1. 读音必须不同
如果干扰项汉字也能读成同一个假名，那它也是正确答案。
例：题干 きかん，不能同时放「期間」和「機関」。
数据里把干扰项读音一起存下来，脚本会检查这一条。

### 2. 汉字+假名混写时，结尾假名必须一致
正确项如果包含假名（如 冷たい、切り裂く、目を通す），干扰项也要
保留相同的结尾假名，否则学生只看假名就能排除。

| 正确项 | 合格干扰项 |
|---|---|
| 冷たい（～たい） | 重たい / 眠たい / 平たい |
| 切り裂く（～く） | 切り開く / 切り抜く / 切り付く |
| 目を通す（～す） | 目を離す / 目を覚ます / 目を凝らす |
| 調べる（～べる） | 比べる / 並べる / 食べる |
| 高層ビル（～ビル） | 低層ビル / 中層ビル / 超高層ビル |

首尾都有假名的词（如 お茶を入れる）优先保留整段假名：
お茶を入れる / お茶を納れる / お茶を給れる（假词）。

### 3. 假词的使用条件
现实里经常凑不出 3 个结尾假名完全相同的真实词。这时：

- **优先**：放宽到“共享最长假名片段”，只用真实词。
- **用户明确同意时**：保留假名、只换汉字，造出假词，例如
  揺さぶる → 由さぶる / 湯さぶる / 油さぶる；
  問いかけ → 話いかけ / 呼びいかけ。

假词虽然一眼能看出“不像词”，但题干里的假名不再能帮助排除，
必须真的认识正确汉字才能选对。数据里把假词读音写成 `"!"`，
校验脚本会跳过同音检查，但仍检查结尾假名。

### 4. 干扰项选择顺序
1. 先按“共享汉字”找：発見 → 発生 / 発想 / 発揮。
2. 再按“同类专名/同场词语”找：四川 → 重庆 / 陕西 / 甘肃。
3. 再按“形近字、同部件、同后缀”找：被害 → 被災 / 損害 / 危害。
4. 最后才用随机同类词兜底。

## 数据与校验

页面数据分三块：

```js
const RAW = [["汉字写法","假名读音","词性","中文释义"], ...];
const CONFUSE = { "词形": ["中文干扰1","中文干扰2","中文干扰3"], ... };
const KANJI_CONFUSE = { "词形": [["汉字干扰","读音"], ...], ... };
```

`CONFUSE` 只服务模式二，`KANJI_CONFUSE` 只服务模式四。
模式一和模式三不需要干扰项数据。

每次改完数据，运行：

```bash
node scripts/validate.mjs <页面.html>
```

脚本会检查：字段完整、无重复词形、含汉字词无同音冲突、干扰项覆盖、
同音干扰、结尾假名、四选项唯一，以及完整的闯关、输入判定、星标、
排序、刷新和旧存档迁移流程。
