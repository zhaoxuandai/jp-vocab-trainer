# 易混干扰项设计手册

三个模式的核心不是“随机凑四个选项”，而是让每个错误选项都值得犹豫一下。
下面的规则来自实际做过的一套 280 词日语词表，可直接套用。

## 通用原则

1. **正确答案只保留一个**。干扰项不能是同一个意思的另一种说法。
   例：正确项是「丈夫」时，干扰项不能再放「老公」「先生」（中文同义）。
2. **同一题的四个选项互不重复**，包括汉字写法、假名、中文释义都不能撞车。
3. **顺序随机**。每次生成后都洗牌，避免“看到 C 就选”。
4. **干扰项优先选真实词汇**。真实词比生造词更难排除。
   只有在“假名完全一致”这类硬要求下找不到足够的真实词时，才允许造词（见下）。

---

## 模式一：看日语选中文

干扰项从下面几类里挑，每类都有具体做法。

### 1. 语义家族
同一场景或同一概念群里的词，最容易混。

| 正确项 | 干扰项示例 |
|---|---|
| 受害者、损失 | 灾害、灾难 / 伤亡、死伤 / 赔偿、补偿 |
| 死者 | 伤者 / 失踪者 / 幸存者 |
| 救护车 | 消防车 / 急救室 / 救援车 |
| 发现 | 发明 / 发生 / 发起 |

### 2. 近义动词
优先选字面相近但含义有差别的词。

- 发生 → 发现 / 发起 / 产生
- 带来 → 带走 / 拿来 / 招致
- 损失 → 损害 / 损耗 / 遗失
- 救出 → 救助 / 抢救 / 解救

### 3. 同一语义场
敬语、亲属称谓、考试、媒体、方位、量词等成组设计。

- 尊敬语 → 谦让语 / 郑重语 / 敬体
- 妻子 → 丈夫 / 女儿 / 母亲
- 口试 → 笔试 / 面试 / 口述考试
- 以上 → 以下 / 以内 / 以外

### 4. 专有名词按类别配
- 地名配邻近地名：四川 → 重庆 / 陕西 / 甘肃
- 人名配形近人名：刘红丽 → 刘红梅 / 张红丽 / 王红丽
- 报纸名配同类报纸：人民日报 → 中国日报 / 光明日报 / 新华日报
- 作品名配同类作品：我是猫 → 我是狗 / 猫的日记 / 人间失格

### 5. 易混点
- 词性陷阱：把名词释义配成动词释义。
- 方向/反义：以上/以下、目上/目下、左/右。
- 量词搭配：…辆、…台 → …张、…片 / …本、…册。
- 双重含义：只放该词在本课中的义项，避免把它的另一个义项当干扰项。

## 模式二：看汉字写假名

干扰项不要从词库里随便抽读音，而是对正确读音做“单点变形”。
这些变形正好对应日语发音的易错点：

### 可用的变形
1. **长音**
   - 去掉长音：きゅうきゅうしゃ → きゅきゅうしゃ
   - おう → おお / お：とうほう → とおほう / とうほ
   - えい → ええ / え：せんせい → せんせえ / せんせ
2. **拗音大小**
   - 小写 → 大写：きゅう → きゆう
   - 大写 → 小写：きやく → きゃく
3. **促音**
   - 去掉：しゅっきん → しゅきん
   - っ ↔ つ：きって → きつて
4. **清浊音 / 半浊音**
   - か行 ↔ が行：とうかい → とうがい
   - さ行 ↔ ざ行、た行 ↔ だ行、は行 ↔ ば行 ↔ ぱ行
5. **片假名长音**
   - ー 的增减：メーン → メン、スピード → スピド

每个词最多取 3 个不同的变形。变形不够时，再从词库里挑
**长度相同、开头相近**的读音补足，不要纯随机。

### 注意
- 正确答案本身不能出现在干扰项里。
- 变形后的假名如果恰好是另一个词的正确读音，仍然可以作为干扰项，
  因为题干是“这个汉字读什么”，不会产生两个正确答案。
- 片假名词和纯假名词没有汉字，通常只在模式一出现；是否放进模式二
  要事先和用户确认。

## 模式三：看假名写汉字

这是最容易做得“没迷惑性”的模式。核心是两条：

### 1. 读音必须不同
题干是假名。如果干扰项汉字也能读成同一个假名，那它也是正确答案。
例：题干 きかん，不能同时放「期間」和「機関」。
写数据时把干扰项读音一起存下来，脚本会检查这一条。

### 2. 汉字+假名混写时，结尾假名必须一致
正确项如果包含假名（如 冷たい、切り裂く、目を通す），干扰项也要
保留相同的结尾假名，否则学生只看假名就能排除。

| 正确项 | 合格干扰项 |
|---|---|
| 冷たい（～たい） | 重たい / 眠たい / 平たい |
| 切り裂く（～く） | 切り開く / 切り抜く / 切り付く |
| 目を通す（～す） | 目を離す / 目を覚ます / 目を凝らす |
| 調べる（～べる） | 比べる / 並べる / 食べる |
| 高層ビル（～ビル） | 低層ビル / 中層ビル / 超高層ビル |

首尾都有假名的词（如 お茶を入れる）优先保留整段假名：
お茶を入れる / お茶を納れる / お茶を給れる（假词）。

### 3. 假词的使用条件
现实里经常凑不出 3 个结尾假名完全相同的真实词。这时有两个选择：

- **优先**：放宽到“共享最长假名片段”，只用真实词。
- **用户明确同意时**：保留假名、只换汉字，造出假词，例如
  揺さぶる → 由さぶる / 湯さぶる / 油さぶる；
  問いかけ → 話いかけ / 呼びいかけ。

假词虽然一眼能看出“不像词”，但题干里的假名不再能帮助排除，
必须真的认识正确汉字才能选对。数据里把假词读音写成 `"!"`，
校验脚本会跳过同音检查，但仍检查结尾假名。

### 4. 干扰项选择顺序
1. 先按“共享汉字”找：発見 → 発生 / 発想 / 発揮。
2. 再按“同类专名/同场词语”找：四川 → 重庆 / 陕西 / 甘肃。
3. 再按“形近字、同部件、同后缀”找：被害 → 被災 / 損害 / 危害。
4. 最后才用随机同类词兜底。

## 数据与校验

页面数据分三块：

```js
const RAW = [["汉字写法","假名读音","词性","中文释义"], ...];
const CONFUSE = { "词形": ["中文干扰1","中文干扰2","中文干扰3"], ... };
const KANJI_CONFUSE = { "词形": [["汉字干扰","读音"], ...], ... };
```

每次改完数据，运行：

```bash
node scripts/validate.mjs <页面.html>
```

脚本会检查：字段完整、无重复词形、含汉字词无同音冲突、干扰项覆盖、
同音干扰、结尾假名、四选项唯一，以及完整的闯关/刷新流程。
